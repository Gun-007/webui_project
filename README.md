# EventNest

EventNest is a college events and activities portal built as a WordPress theme and plugin. The repository contains the EventNest code; each developer installs WordPress and keeps their own local database and uploads.

## Quick links

- [Team setup and workflow guide](docs/TEAM_SETUP.md)
- [EventNest Core plugin notes](wp-content/plugins/eventnest-core/README.md)

## Repository contents

- `wp-content/themes/eventnest/` — EventNest interface, home page, event archive and event detail templates.
- `wp-content/plugins/eventnest-core/` — event/club records, roles, accounts, registrations, proposals, and review workflow.
- WordPress core, local configuration, database, and media are intentionally excluded from Git.

## Current workflow

Students can register for events, manage their registrations, submit proposals, and track decisions. Faculty/Club Heads and higher reviewers can review proposals. Final approval creates a draft event; an administrator completes its details and publishes it.
